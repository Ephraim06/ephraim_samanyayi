Project Overview

What is the EMS App?

The Event Management System (EMS) is a full-stack web application that allows organizations to plan, manage, and track events seamlessly. It includes tools for task assignment, contact management, event registration, venue tracking, and Kanban-style task boards.

Key Features

  • Event creation and scheduling
  • Pre-event task manager with drag-and-drop Kanban board
  • Contact management and automatic CRM creation on registration
  • Venue facilities listing and assignment

What's Next

  • Role-based permissions for admins, organizers, and attendees
  • Ticket generation for event registrants
  • Event analytics dashboard and reporting tools

The Challenge

Event planning often involves scattered tools, manual tracking, and poor visibility into task progress. Organizations needed a centralized system that brings everything together.

  • Fragmented tools causing miscommunication between teams
  • No visual task tracking for pre-event workflows
  • Manual contact management leading to data duplication
  • Lack of centralized venue and facility information

Development Solutions

Kanban Task Management

Implemented drag-and-drop task boards using @dnd-kit for intuitive pre-event workflow management with real-time status updates.

Integrated CRM

Automatic contact creation upon event registration, eliminating manual data entry and reducing duplicate records.

Modern Tech Stack

Laravel backend with React frontend via Inertia.js, styled with Tailwind CSS for a responsive, fast user experience.
